# 🏪 Store Sales Analysis Using Python & SQL

An end-to-end **Data Analytics project** focused on analyzing store sales data using **Python and SQL** to understand sales performance, product performance, customer purchasing patterns, store-level performance, and business trends.

The project combines **SQL-based data analysis** with **Python-based exploratory data analysis and visualization** to transform raw sales data into meaningful business insights.

---

## 📌 Project Overview

The objective of this project is to analyze store sales data and identify important patterns related to sales, products, customers, stores, and time.

The project focuses on answering key business questions using SQL queries and Python analysis.

The analysis covers:

* Sales performance
* Store performance
* Product performance
* Customer purchasing behavior
* Sales trends
* Quantity sold
* Revenue analysis
* Category performance
* Time-based sales patterns

The project follows an end-to-end analytics workflow:

**Raw Data → Data Cleaning → SQL Analysis → Python EDA → Visualization → Business Insights**

## 🎯 Business Objectives

The main objectives of this project are:

* Analyze overall store sales performance

* Understand sales trends over time
